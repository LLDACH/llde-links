# Lottoland Deutschland Link Page

A responsive, static link page for GitHub Pages.

## Included
- `index.html` — Lottoland header, eight requested links and divider
- `style.css` — clean light-grey layout and branded button styling
- `images/` — supplied lottery artwork and Lottoland SVG logo

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub Pages will publish the site at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

## Image note
The Lottoland PNG filename mentioned for button 2 was not attached with this batch. The previously supplied Lottoland master SVG logo is used for that thumbnail instead. If you upload the PNG, replace the second link image source in `index.html` with its filename.


## Responsive header
The header uses a compact horizontal layout on desktop and smaller screens, with the logo beside the heading and subline. The logo scales down on narrow phones to preserve readable text.
